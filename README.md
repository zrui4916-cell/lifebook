# 人生书 LifeBook

以书籍章节组织日常计划和成长记录的可交互 Web 产品原型。

**在线 Demo：** https://lifebook-career-demo.pages.dev

**GitHub：** https://github.com/zrui4916-cell/lifebook

## 产品体验

- 一句话描述当前阶段，形成章节与关键词。
- 自然语言任务整理，支持修改类型、日期、重要程度和方向后确认。
- 今日事项、月历计划、任务完成与删除。
- 封面章节、完成记录、阅历与成长回顾。
- 浏览器本地存储，刷新后恢复记录。

## 运行

使用 Node.js 22.13 或更高版本：

```sh
npm install
npm run dev
```

```sh
npm run build
npm run preview
```

构建输出 `dist/` 可上传 Cloudflare Pages。框架为 React + TypeScript + Vite；源码由原 Next.js / vinext 工程的单页交互组件整理而来，样式复用已生成的 CSS。首次安装后应提交对应依赖锁文件。

## 免费 Demo 的边界

自然语言整理采用关键词与日期规则，不调用线上大模型；`askDeepSeek` 保留原交互调用接口并立即进入本地回退逻辑。记录存放于当前浏览器 `localStorage`，不支持账号或跨设备同步。清除浏览器数据后记录会丢失。

目前回顾按任务截止日期关联，未区分真实完成时间；复杂日期表达需在确认卡中修正。账号同步、提醒、模型能力和完整存储容错是后续方向。

## 交付与验证
